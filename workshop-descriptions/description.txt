[h1]Phobos EPR Cleanup[/h1]
A small utility mod that removes all [b]Extensive Power Rework (EPR)[/b] data from your save files, allowing you to cleanly uninstall EPR without lingering side effects.

[b]Does NOT require EPR to be loaded.[/b] In fact, EPR must be disabled first — the mods are declared incompatible and cannot both be active.

[hr][/hr]
[h2]The Problem[/h2]
The EPR mod (Workshop ID 3643765614) crashes on load in certain PZ Build 42 versions, leaving orphaned data in save files that causes:

[list]
[*][b]Power and water never shutting off[/b] — EPR sets ElecShutModifier and WaterShutModifier to max int (2147483647), permanently written to your sandbox options file
[*][b]Water coolers showing "zone is offline"[/b] — EPR modifies building power/water state which persists without the mod loaded
[*][b]Orphaned world modData[/b] — EPR_GridData, EPR_PowerController, EPR_GlobalData, and EGO_GridData remain in your save file
[/list]

[hr][/hr]
[h2]What It Does[/h2]
On first game load after enabling this mod, it automatically performs three cleanup steps:

[list]
[*][b]Restores sandbox variables[/b] — Reads EPR's backed-up original ElecShutModifier/WaterShutModifier values and writes them back to disk, so power and water shut off at the correct in-game day again
[*][b]Resets building state[/b] — Calls setHasElectricity(false) / setHasWater(false) on all EPR-connected buildings, letting vanilla mechanics re-evaluate power (buildings near working generators will regain power normally)
[*][b]Removes EPR world modData[/b] — Deletes EPR_GridData, EPR_PowerController, EPR_GlobalData, and EGO_GridData from the save
[/list]

A modal dialog appears on screen summarising exactly what was cleaned.

[hr][/hr]
[h2]What It Does NOT Do[/h2]
[list]
[*]Does [b]not[/b] scan every world object for EPR_SpriteGenerator markers on individual generators — these orphaned boolean markers are harmless when EPR is not loaded
[*]Does [b]not[/b] modify save files on disk directly — operates through PZ's normal modData API at runtime
[*]Buildings not currently loaded in memory (far from the player) may retain EPR state until visited — use Force Re-run if needed
[/list]

[hr][/hr]
[h2]Usage[/h2]
[olist]
[*]Unsubscribe from or disable EPR (the mods cannot both be active)
[*]Subscribe to [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3668598865][b]PhobosLib[/b][/url] and [b]PhobosEPRCleanup[/b]
[*]Enable both mods in your mod list
[*]Load your save — cleanup runs automatically on first load
[*]Check the on-screen modal for results
[*]Unsubscribe from PhobosEPRCleanup (and PhobosLib if no other Phobos mods are installed)
[/olist]

[th]Option[/th]
[th]Default[/th]
[th]Description[/th]

[td]Run EPR Cleanup[/td]
[td]ON[/td]
[td]Execute full EPR data removal on next load[/td]
[/tr]
[tr]
[td]Restore Sandbox Variables[/td]
[td]ON[/td]
[td]Restore ElecShutModifier/WaterShutModifier to pre-EPR values[/td]

[tr]
[td]Force Re-run[/td]
[td]OFF[/td]

[/tr]
